## 📋 Overview

This repository contains the complete production-ready Public Key Infrastructure (PKI) for EHEPS International Organization, implementing:

- **RFC 5280** - X.509/PKIX certificate profiles
- **RFC 3279** - Historical algorithm references
- **RFC 8996** - TLS 1.0/1.1 prohibition
- **CA/Browser Forum** - Baseline requirements
